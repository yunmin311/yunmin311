## 👋 Hi, I'm liqiyu · yunmin311

设计师,不是工程师 —— 但我把"想法"做成真能跑的工具。
*A designer, not an engineer — I turn ideas into tools that actually run.*

我在造一套**给自己用的多 AI 治理系统**:让一堆 AI(Claude / Codex / …)像一个团队那样协作,而**人是唯一的拍板者**。信条:最小加载、本地优先、零依赖、换台机器也不塌。
*Building a personal governance system for the many AIs I work with — many models acting as one team, with a human as the sole approver. Minimal-loading, local-first, built to survive a machine swap.*
